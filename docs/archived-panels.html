A naive coupling number is mostly artifact. The filter removes it, correctly — (a) is an artifact. The physiological coupling (c) was never what the number was reporting.

How each row is computed

(a) is the component locked to respiratory phase, in µV. “of injected” compares it against ground truth at the electrode — the source amplitude times the gain of projection and of the reference you picked, both linear and both known exactly. Charging that geometry to the filter would be the same conflation this demo is about.

Noise floor is the same estimator run off-resonance, where nothing was injected. It is not zero, so compare (a) against the floor rather than against zero.

(c) is named by mechanism, not quantity. It reads χ̂ at the respiratory rate, where both halves of mechanism (c) can appear, in true χ units. It is a control that does not move with the filter — not a clean measurement of exponent modulation, since the shipped depth sits only ~3× above the floor.

Ground truth exists here only because the generator injected it; no real dataset can show this comparison. G4 runs it on a 300 s record because a 30 s window cannot separate the modulation from its sidebands.

Effective rank is the participation ratio of the channel covariance — a threshold-free count of how many independent things 19 electrodes are actually carrying. It is far below 19, and it should be: volume conduction guarantees that. But a value near 1 would mean every channel is the same trace scaled, which no recording looks like.

The two exponents are different quantities, not two estimates of one. Comparing them is a type error in the source.
